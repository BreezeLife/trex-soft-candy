# 霸王龙软软糖 / T-Rex Jelly · Android

安装文件：`trex-jelly-android-v1.3.0.apk`（手机和平板通用安装测试版）。

把 APK 发送到 Android 手机或平板，打开后按系统安装提示操作。最低系统版本为 Android 8.0，图形设备需支持 WebGPU 或 WebGL2。应用内置完整资源，可以离线使用；进入后可选择中文或 English。

- 单指抓住恐龙拉伸；双指缩放，空白处拖动转视角。
- 顶部按钮进入/退出全屏。Android 返回键先关闭玩法面板或沉浸视图，再退出应用。
- “更多玩法”调整软硬、摇晃方式、慢动作、网格与视角。
- 支持手机和平板横竖屏，不申请网络、存储、相机或麦克风权限。

此包使用项目本地开发签名，供直接安装测试；不是 Google Play 商店发行包。编译、签名、资源核对与浏览器测试结果见根目录 `TEST_REPORT.md`。没有实际 Android 手机/平板验收结果前，不将浏览器窗口尺寸测试标成安卓真机通过。

源码、构建方法与本地资源安全策略见 `../android/README.md`。私有签名文件与构建缓存不属于交付包。
